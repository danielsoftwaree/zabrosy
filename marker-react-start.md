# Задание для coding-агента

Создай React web/PWA «Маркер» по `SPEC.md`. Визуальный и поведенческий референс — `reference/marker-mobile.html`, исходники — `reference/legacy-source/src/`. Целевые контракты — `contracts/domain.ts`, порядок задач — `IMPLEMENTATION.md`.

Это перенос работающего прототипа, а не новый dashboard. Сектор занимает главный экран, управление находится поверх него; приложение рассчитано на портретный телефон. Длинные объяснения только в справке. Не добавляй регистрацию, backend, серверную синхронизацию или автоматическое восстановление глубин.

Стек: React + TypeScript strict + Vite; Canvas 2D для сектора и схемы наблюдений; Dexie/IndexedDB; типизированные команды и небольшой store; MapLibre загружать отдельно только для снимка. Не складывай всё в App.tsx и не перерисовывай React-дерево на каждом sensor/pointer event.

Сначала прочитай HTML, `core.js`, тесты и требования к измерениям. Создай проект, перенеси чистые функции и опиши миграции. Затем реализуй один вертикальный сценарий: выбрать направление → вода → дно → обороты → ощущение → полная/частичная подмотка → сохранение → reload → восстановленные данные. Только после этого добавляй карту, датчики и 3D.

Главные инварианты: обороты — ручки, не ротора; q фиксируется в snapshot заброса; 50 × 0,8 = 40 м, отметка на 10 оборотах = 32 м; частичная подмотка не определяет полную длину; метры по карте не равны леске; отрицательная предварительная позиция не становится нулём; секунды не становятся глубиной; нулевую глубину не подставлять вместо неизвестной.

Кандидат может находиться на отметке внутри луча. Повтор заброса обязан учитывать станцию и новый ориентир. Сохрани импорт v1/v2, backup исходника и portable HTML; не исполняй импортированную разметку. Обновление PWA не прерывает промер. Разрешения и интернет необязательны для сектора.

Выполняй этапы `IMPLEMENTATION.md`, отмечая фактические результаты, а не будущие обещания. Тестируй storage и Service Worker на сборке через server. Датчики сначала проверяй адаптерными тестами; не называй поддержку телефона проверенной без физического теста. В завершении укажи, что сделано, результаты команд, ограничения и статус публикации. Не подменяй приложение статическим макетом.
