# Основа приложения · спецификация

**Статус:** локальный полевой срез реализован. Автоматические проверки и оставшаяся внешняя приёмка перечислены в [задачах](../tasks/foundation.md).

## Поведение

1. Приложение открывается на телефоне без регистрации, разрешений и env Supabase. Пустая локальная установка показывает сектор и ясное действие начала промера.
2. Действия промера и расчёты существуют как чистая логика отдельно от UI. Ошибочные переходы не превращаются в сохранённый заброс.
3. Данные и черновик переживают reload в одном браузере. Ошибка сохранения видима пользователю. По умолчанию данные не уходят в облако.
4. Доступность датчиков показывается честно. Ручной выбор направления и ввод остаются доступны всегда.
5. На устройстве с HTTPS приложение можно добавить на экран «Домой» и открыть после первоначальной загрузки без сети. Обновление не прерывает активный промер.
6. Подключение Supabase требует только URL и publishable key. Аккаунт и синхронизация реализованы с миграциями и RLS; для проверки реального сервиса нужен проект Supabase.

## Инварианты измерений

- Обороты — обороты ручки катушки. Выборка в метрах на оборот фиксируется при начале заброса.
- 50 оборотов при 0,8 м/оборот дают 40 м выбранной лески. Отметка за 10 оборотов до конца при полной подмотке соответствует 32 м по леске.
- Неполная подмотка сама по себе не задаёт полную длину заброса.
- Время падения остаётся временем; без отдельного измерения глубина неизвестна.
- Расстояние на карте и длина лески — разные величины. Неизвестная позиция не подменяется нулём.

## Достаточная проверка

Unit-тесты на расчёты и существенные переходы; интеграционная проверка локального сохранения и восстановления; один браузерный путь первого промера и reload, когда PWA и storage готовы. Проверка гироскопа и компаса на реальном iPhone оформляется отдельным результатом: модель, iOS, браузер, разрешения и наблюдаемая точность. Эмуляция не считается такой проверкой.
