# Статус рабочего приложения

26 сентября 2026 года. Это рабочая локальная PWA, а не только архитектурный каркас. Дизайн предварительный.

## Реализовано

- [x] TanStack Start, React/TypeScript, Base UI, Phosphor, tooling, AI harness и закреплённые skills.
- [x] Работа без env, сети, аккаунта и аппаратных разрешений; облаку нужны два публичных env.
- [x] Сессии, калибровка, сектор и основной цикл промера; черновик переживает перезапуск, недостоверный таймер прерывается.
- [x] Обороты, ощущения, отмена шага, полная/частичная подмотка, ручная глубина с отдельной привязкой положения.
- [x] Журнал, исправления, избранное, повтор заброса, защита разных станций/ориентиров.
- [x] Атомарная IndexedDB-запись и взаимодействие нескольких вкладок.
- [x] JSON/CSV/PNG и автономный редактируемый HTML; импорт копий, восстановление черновика и сохранение старого v2-исходника.
- [x] GUGiK: проверенный живой снимок 1200×1200 в точке пользователя; ручные координаты без снимка, станция/ориентир/цель, отдельная дальность по карте.
- [x] Камера по нажатию, наведение через ориентир, ручной режим, остановка потока при уходе и скрытии страницы.
- [x] GeoJSON-точки с источником/датумом, отдельный слой глубин, виды сверху/по дальности/3D и явно включаемая ограниченная IDW-оценка.
- [x] Настройки вида и источника рельефа открываются в нижнем листе; запуск камеры и остановка потока находятся в кадре, а ручное наведение — в отдельном листе. На снимке выбранная точка и координаты используют один нижний блок; полевой док на видах карты компактен. Настольный экран показывает один мобильный iframe текущего маршрута.
- [x] Опциональное удержание экрана, диагностика датчиков/GPS, памятка установки PWA.
- [x] Вход по имени и общему паролю через Supabase Edge Function, браузерный PostgREST-обмен с Auth/RLS, ревизии и tombstones, выбор конфликтной версии, защита смены аккаунта и непереданных изменений.
- [x] Статическая сборка GitHub Pages с путём `/zabrosy/`, HTML для прямого открытия маршрутов и workflow публикации.
- [x] Service worker с полной локальной оболочкой и переносимым шаблоном; обновление по действию после завершения промера.

## Проверки

- Заключительные TypeScript, ESLint, 51 unit-тест и статическая сборка `npm run build:pages` прошли.
- На локальном HTTP-превью статического артефакта `/zabrosy/` прошли 19/19 Playwright-сценариев Chromium: полный и прерванный промер, офлайн-маршруты, JSON/HTML/GeoJSON, две вкладки, отказ камеры и ориентации, сохранение выбранной точки после создания сессии, выбор глубин через нижний лист и навигация в единственном настольном iframe. Сценарий входа проверяет форму и отказ Edge Function без создания сессии. Гидратация прямых маршрутов проверена без ошибок React.
- На снимках 320×568, 390×844 и 1280×900 вся схема глубин находится выше компактного дока (69 px), навигация начинается на 8 px сверху, горизонтального переполнения и ошибок страницы нет.
- SQL-миграция и `supabase/tests/rls.sql` выполнены во встроенном PostgreSQL (PGlite). Роли и auth.uid/users воспроизведены локально. Проверены собственные записи, изоляция другого пользователя, составной FK, ревизии, запрет anon и отказ обычному Auth-профилю без серверного `app_metadata.marker_username` даже при подложном `user_metadata`. Это не проверка сервиса Supabase Auth или удалённого проекта.
- Обновлённый полевой экран проверен при 320×568, 390×844 и 1280×900: главное действие видно, горизонтального переполнения и ошибок страницы нет. Живой GUGiK ранее вернул изображение 1200×1200.

## Внешняя приёмка и границы

- [x] Реальный Supabase: применена миграция `20260926094535_survey_cloud`, заданы серверные секреты и развёрнут `marker-login`. Проверены отказ неверному паролю, вход двух временных профилей, создание/чтение/обновление собственных сессий и забросов, изоляция второго профиля и запрет анонимного доступа. Временные профили и записи удалены.
- [ ] Проверка синхронизации на двух физических устройствах остаётся отдельной от API-тестов.
- [ ] GitHub Pages: создать репозиторий, задать две публичные repository Variables, включить Pages через GitHub Actions и проверить живой адрес. Локальный workflow и статический артефакт не означают публикацию.
- [ ] Физический iPhone: установка, камера, ориентация, энергосбережение, точность в поле, обновление установленной PWA.
- [ ] Конкретный файл CARIS/ENC: определить формат, покрытие, глубины, вертикальную основу и права. Сырой S-57/S-63 не открывается; подготовленный GeoJSON поддерживается.
- Камера — средство наведения, не точный дальномер. Леска и горизонтальная дальность не усредняются. Течение и положение груза автоматически не вычисляются.
- Интерполяция не распознаёт берега и не является батиметрической съёмкой; нужна явная проверка одного водного участка. Предпросмотр ограничен 1000 точками.
- Перенос старого v2 сохраняет исходник; неподтверждённые поля не превращаются в измерения. Неизвестный v1 требует отдельного анализа.
- Автономный HTML работает в памяти; изменения нужно повторно экспортировать до закрытия.

В сборке сохранён временный обход Nitro 3.0.0: после завершения Vite принудительно завершается оставшийся дочерний процесс prerender. Удалить после исправления upstream.
