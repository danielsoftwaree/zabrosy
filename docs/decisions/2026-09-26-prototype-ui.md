# Полевая компоновка из marker-mobile.html

По прямому запросу пользователя исходный `marker-mobile.html` теперь служит визуальным ориентиром для рабочего полевого экрана. Сектор занимает высоту окна за шапкой и нижним доком. В доке находятся оценка длины лески, направление, большое действие таймера, счётчик подмотки и шесть быстрых отметок ощущений. Точные значения, калибровка, выбор сессии, исправление отметок и сохранение открываются в доступных нижних листах Base UI. Снимок, камера и дно используют ту же рабочую область над доком.

Это решение касается композиции первого полевого экрана, а не утверждения полной дизайн-системы. Общие цвета и компоненты пока можно менять без миграции предметных данных.

Предварительная длина `plannedLineM` хранится отдельно в сессии и снимке заброса. Она обозначена знаком «≈» и используется для направления луча до завершения подмотки. Измеренная по полной подмотке длина по-прежнему считается из оборотов и снимка калибровки; предварительная оценка не подменяет её, не становится горизонтальной дальностью и не создаёт глубину. Сохранённая цель также не становится подтверждённым положением глубины без отдельного действия пользователя.

Предметная модель, локальное сохранение и синхронизация остаются общими для сектора и других представлений. Новая компоновка не меняет правила прерывания таймера, повторения заброса и чтения старых записей без `plannedLineM`.
