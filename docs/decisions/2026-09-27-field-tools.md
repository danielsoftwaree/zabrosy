# Canvas-карта, источники и камерная оценка

27 сентября 2026. Основание — [запрос на полевые инструменты](../specs/field-tools-upgrade.md).

- Добавлен OpenLayers: требуются настоящие жесты карты и тайлы второго поставщика. Canvas отображает снимок и географические отметки; доступные действия и нижний drawer остаются HTML/React. Canvas сам по себе не заменяет семантику кнопок и форм.
- Экранная проекция EPSG:3857 сохраняет локальные углы и пропорции. WMS GUGiK в этой проекции проверен живыми JPEG на точке пользователя, хотя прежнее исследование отмечало неполный список CRS в capabilities. Расстояния вычисляются из WGS84, чтобы метры Web Mercator не выдавались за реальные метры.
- Esri World Imagery добавлен как дополнительный поставщик для сравнения и резерва. Дата и разрешение конкретного листа не обещаются. Внешние снимки не попадают в PWA precache или экспорт карт; атрибуция видима, коммерческое использование требует отдельной проверки условий.
- Камерная оценка использует `h / tan(θ)` для точки на горизонтальной воде. Калибровка по известной дистанции предпочтительна на реке; дальний берег не считается горизонтом. Высота подтверждается явно, ошибки и нестабильность приводят к отказу. Показанный диапазон — чувствительность при допущениях, не измеренная точность устройства. Подробности — [исследование AR](../research/ar-distance-2026-09-27.md).
- Снимок последней камерной оценки хранится в sessionStorage вместе со временем и калибровкой. Это не запись Cast и не облачный промер. Дальность до цели по карте остаётся независимым показателем; результаты не усредняются.
- Для глубин найден официальный Inland ENC P17OD735 с изобатами и областями глубин, охватывающий рамкой Цегелинку. Извлечённые данные не распространяем без письменного разрешения UZS; приложение даёт официальные ссылки на файл и просмотрщик. Внутренний GeoJSON-импорт остаётся для разрешённых пользователю точек. [Источники и ограничения](../research/szczecin-sources-2026-09-27.md).
