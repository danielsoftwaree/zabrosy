# Предметная область Маркера

Маркер помогает рыболову записать ручной промер с берега: направление заброса, время падения груза, обороты ручки катушки и ощущения при подмотке. Значения служат для сравнения забросов; приложение не измеряет рельеф автоматически. Это словарь для спецификаций, кода и тестов. Модель развивается; наличие термина здесь не означает готовую функцию.

| Термин | Значение |
|---|---|
| **Сессия / Session** | Одна рыбалка или логически собранный набор забросов. Может включать несколько мест на берегу. |
| **Промер** | Последовательность действий пользователя от выбора направления до подтверждения записи. Пока не подтверждён, существует как черновик. |
| **Заброс / Cast** | Сохранённый результат одного промера с неизменяемым снимком исходных настроек. |
| **Станция / Station** | Физическое место пользователя на берегу с устойчивым ID. Смена берега создаёт новую станцию. |
| **Рамка / SurveyFrame** | Версия геопривязки станции: координаты и нулевой ориентир. Смена ориентира создаёт новую рамку, не переносит старые забросы. |
| **Ориентир** | Видимая точка, задающая локальный угол 0°. Относительный угол не является сам по себе азимутом на север. |
| **Оборот** | Полный оборот **ручки катушки**, а не ротора. `N` — число оборотов при полной подмотке, `nᵢ` — счётчик у конкретной отметки. |
| **Выборка `q`** | Оценка метров лески за оборот ручки, полученная калибровкой либо явно помеченная оценкой. Значение фиксируется в забросе при старте. |
| **Отметка / BottomMark** | Ощущение или наблюдение пользователя при протяжке, привязанное к счётчику оборотов. Не является автоматически определённым типом дна. |
| **Цель / Target** | Выбранная пользователем точка или интервал для повторной проверки, в том числе кормушкой. |
| **Время падения** | Вручную измеренный интервал от касания воды до ощущения дна. Это секунды, не глубина. |
| **Длина лески** | Оценка по оборотам и `q`, при полной подмотке `N × q`. Не равна расстоянию по карте или фактической траектории груза. |
| **Глубина** | Отдельное измерение с указанным происхождением; при его отсутствии значение неизвестно, а не `0`. |

Эталон расчёта: `q = 0,8 м/оборот`, `N = 50` дают около `40 м` выбранной лески; отметка за `10` оборотов до конца соответствует примерно `32 м` по леске. Неполная подмотка не доказывает полную длину заброса.

Актуальные решения о модулях и backend находятся в [архитектуре](docs/architecture.md); критерии ближайшей реализации — в [спецификации](docs/specs/foundation.md). Старый [подробный анализ](marker-react-spec.md) полезен для предметных правил, но его прежние решения о стеке и дизайне заменены.
